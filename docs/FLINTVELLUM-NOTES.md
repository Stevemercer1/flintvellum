FlintVellum’s fingerprint.js is unchanged, with exactly one hook immediately before the closing body tag on every generated page. The original publisher’s trackers remain detached.

Rebuild with `python3 docs/populate.py`. Append supplied records with `python3 docs/populate.py ../catalogue-expanded-259`. The importer rejects conflicting existing IDs and image hashes, skips duplicate source URLs and never copies a report. Reimporting the same dataset adds nothing. The catalogue leads with the additions, followed by a stable mixed-category order. This first runs rebrand.py against the saved christies-pristine tag, then applies the current content. Do not run rebrand.py alone for publishing.

`python3 docs/verify-data.py` checks every generated route, local asset, original photograph hash, attribution, protected copy and analytics hook. `node docs/verify.cjs` exercises the site in Firefox, including search, filters, saving, galleries, navigation and narrow layouts. The `--company` mode checks the careers and settlement routes. The `--motion` mode covers mouse dragging, keyboard selection, normal links, scroll effects, reduced-motion changes and content without JavaScript. The `--enquiry` mode covers rate arithmetic and failures, expiry, email draft encoding and expanded-form layouts. The `--currency-live` mode verifies a real Coinbase request in Firefox. Screenshots stay in ignored docs/verify-shots/.

The homepage uses experience.css and experience.js for progressive scroll reveals, subtle image movement and a reading-progress line. The mirrored carousel code supports mouse dragging, touch and keyboard controls. Reduced motion disables movement, keyboard selections are immediate, and content stays visible without JavaScript. Each homepage photograph is unique.

The owner chose confirmed availability only and delegated the selection. No current stock was confirmed, so open bidding stays disabled. A stable hash assigns 82 objects to an enquiry-only sourcing route for a similar piece; 177 retain the closed presentation. Source records are never changed. Visitors can prepare a proposed GBP budget and settlement preference, copy a draft or open their own email app. No inbox is invented, no form claims delivery, and no bids are accepted. The protected recruitment mailto remains unchanged.

Object pages offer an optional GBP reference converter using [Coinbase's documented public exchange-rate endpoint](https://docs.cdp.coinbase.com/coinbase-app/track-apis/exchange-rates). Requests run only when the panel opens, use no credentials, and cover Bitcoin, Ethereum, USDC and USDT separately. Rates expire after five minutes in the browser. Failures, invalid responses and expired references clear the conversion instead of substituting a rate. These are indicative figures excluding fees, not settlement quotes.
